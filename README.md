### Задание 1


На лекции рассматривались режимы репликации master-slave, master-master, опишите их различия.

_Ответить в свободной форме._
Основные различия режимов репликации:
Master-Slave
1. Архитектура: Один сервер мастер, остальные — слейвы
2. Операции записи: Все записи происходят только на мастере, слейвы запись не выполняют.
3. Операции чтения: Чтение происходит на слейвах, что разгружает мастер.
4. Отказоустойчивость: Высокая для операций чтения, но запись возможна только при доступности мастера.
5. Сложность конфигурации: Простой вариант настройки.
6. Синхронизация: Однонаправленная передача данных — мастер-лидер.
----
1. Архитектура: Все серверы равноправны, каждый выступает как мастер и как слейв.
2. Операции записи: Записи можно проводить на любом сервере системы.
3. Операции чтения: Чтение возможно на всех серверах одновременно.
4. Отказоустойчивость: Более высокая; система продолжает работу даже в случае сбоя одного из мастеров.
5. Сложность конфигурации: Более сложная настройка, требуется решение конфликтов данных при одновременных записях.
6. Синхронизация: Двунаправленная синхронизация между мастерами.

### Задание 2

Выполните конфигурацию master-slave репликации, примером можно пользоваться из лекции.

*Приложите скриншоты конфигурации, выполнения работы: состояния и режимы работы серверов.*

1. Файлы конфигурации были созданы согласно конспекту. Находятся в папке [12-06](/12-06)
2. Запущены сервера в контейнерах
```
docker build -t mysql_master -f ./Dockerfile_master . 
docker build -t mysql_slave -f ./Dockerfile_slave . 
docker network create replication 
docker run --name mysql_master --net replication -p 3306:3306 mysql_master 
docker run --name mysql_slave --net replication -p 3307:3306 mysql_slave
```
